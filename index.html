How I work

Three things I hold myself to on every project.

01

Ship the whole system

I don't stop at a UI mockup. Every project I list has a real backend behind it: schema design, authentication, and the edge cases that only show up once data starts moving.

02

Write it so someone else can read it

Clean, maintainable code over clever code. MediCore's role-based access and billing logic is covered by a Jest and Supertest suite, not just manual clicking around.

03

Build for the people who need it most

The projects I choose to build lean toward healthcare, education and public services. Technology matters most where the stakes are highest, and that's especially true across Africa.
